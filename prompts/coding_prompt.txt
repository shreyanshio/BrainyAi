User: "Write an LRU Cache in Python with O(1) get and put operations."

Expected Response Pattern:
[Architecture]
An LRU (Least Recently Used) Cache requires O(1) time complexity for both `get` and `put`. This is achieved using a Hash Map combined with a Doubly Linked List (or Python's `collections.OrderedDict`). Here is the standard interview and production implementation using a custom Doubly Linked List to demonstrate the underlying mechanics.

[Code]
```python
from typing import Optional, Dict

class Node:
    __slots__ = ('key', 'val', 'prev', 'next')
    def __init__(self, key: int = 0, val: int = 0):
        self.key: int = key
        self.val: int = val
        self.prev: Optional['Node'] = None
        self.next: Optional['Node'] = None

class LRUCache:
    """
    Least Recently Used (LRU) Cache with O(1) get and put operations.
    Maintains dummy head and tail nodes to eliminate edge-case pointer null checks.
    """
    def __init__(self, capacity: int):
        if capacity <= 0:
            raise ValueError("Capacity must be positive.")
        self.capacity = capacity
        self.cache: Dict[int, Node] = {}
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node: Node) -> None:
        p, n = node.prev, node.next
        if p and n:
            p.next = n
            n.prev = p

    def _insert_to_front(self, node: Node) -> None:
        node.next = self.head.next
        node.prev = self.head
        if self.head.next:
            self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._remove(node)
        self._insert_to_front(node)
        return node.val

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            node = self.cache[key]
            node.val = value
            self._remove(node)
            self._insert_to_front(node)
            return

        if len(self.cache) >= self.capacity:
            lru = self.tail.prev
            if lru and lru != self.head:
                self._remove(lru)
                del self.cache[lru.key]

        new_node = Node(key, value)
        self._insert_to_front(new_node)
        self.cache[key] = new_node
```

[Complexity]
- Time Complexity: `get(key)` is O(1) hash table lookup + O(1) node pointer update. `put(key, value)` is O(1) hash table update + O(1) node insertion/removal.
- Space Complexity: O(capacity) to store at most `capacity` entries in the hash map and doubly linked list.

[Edge Cases Handled]
- Key eviction when capacity is 1 or full.
- Updating an existing key without increasing cache size.
- Querying non-existent keys returns `-1` gracefully without throwing KeyError.
