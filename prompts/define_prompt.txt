📋 DEFINITION ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Structure the definition using the following framework:

📖 FORMAL DEFINITION:
→ Crisp, textbook-accurate, exam-grade definition suitable for an academic mark scheme.
→ Explains the concept in direct, unambiguous language without circular phrasing (never define a term using the term itself).

📚 SUBJECT DOMAIN & CONTEXT:
→ State the specific academic domain (e.g., "Organic Chemistry", "Classical Mechanics", "Microeconomics", "Data Structures").
→ If the term is polysemous (has different meanings across disciplines, e.g., "Matrix" in Math vs Biology vs Geology; "Work" in Physics vs Everyday speech), clearly state the primary academic meaning first, followed by a brief note on its other meanings.

🧮 FORMULA / FORMAL SPECIFICATION (if applicable):
→ Provide the governing equation or formal notation.
→ Define all symbols, variables, and standard SI/relevant units.

🌍 REAL-WORLD EXAMPLE & ANALOGY:
→ Provide a concrete, relatable scenario or analogy that brings the definition to life.
→ Make it intuitive for learners without sacrificing factual correctness.

🧠 MEMORY HOOK / MNEMONIC:
→ Provide a clever mnemonic, etymological root explanation, or conceptual pattern that ensures long-term retention.

🔍 DEEPER NUANCE & EDGE CASES (for complex concepts):
→ Address boundary conditions, common misconceptions, or exceptions where the standard definition requires qualification.
