# Getting Support for Brainy AI

Thank you for using **Brainy AI**! Whether you are a student utilizing the study companion or a developer deploying your own instance, here is how you can find help and report issues.

---

## 1. Documentation & Guides

Before reaching out, check our comprehensive documentation:

* **[README.md](README.md)**: Main architecture overview, feature list, and quick start guide.
* **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**: Deep dive into system topology, authentication flows, and multi-provider routing.
* **[docs/API.md](docs/API.md)**: Authoritative REST API reference for all endpoints.
* **[docs/DATABASE.md](docs/DATABASE.md)**: Supabase PostgreSQL schema, tables, and RLS policies.
* **[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)**: Production deployment instructions for Cloudflare Workers and Railway.
* **[CONTRIBUTING.md](CONTRIBUTING.md)**: Development guidelines, code standards, and verification checks.
* **[SECURITY.md](SECURITY.md)**: Security policy and instructions for reporting vulnerabilities.

---

## 3. Reporting Issues

* **Bug Reports**: If you encounter unexpected behavior, broken functionality, or a regression, please submit a bug report using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
* **Feature Requests**: If you have an idea for a new study tool or architectural improvement, submit a request using our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
* **Security Vulnerabilities**: **DO NOT** report security vulnerabilities in public issues. Please follow the instructions in [SECURITY.md](SECURITY.md) to report security concerns privately.

---

## 4. Scope of Support

Brainy AI is an open-source, community-driven academic project developed and maintained by volunteers. 

* Support is provided on a best-effort basis through GitHub issues and community discussions.
* Direct one-on-one consulting or SLA-backed enterprise support is not offered.
